    How the odds work

    Every unknown card is drawn from the actual remaining deck — known hole cards, the board, and mucked cards are removed first, so probabilities update exactly as cards appear. When only the board runout is unknown the result is computed by exact enumeration; otherwise a fast Monte-Carlo simulation is used. Reference probabilities.
